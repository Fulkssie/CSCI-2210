# Project 4
## Library Kiosk System

The language I used is: c++.exe (Rev10, Built by MSYS2 project) 15.2.0

### Instructions
1. Download Project 4 folder from GitHub
2. Open the folder in VSCode
3. Setup a C++ environment if you havent. I used the vscode tutorial: https://code.visualstudio.com/docs/languages/cpp
4. In the terminal, move to the folder
5. In the terminal, run this command: g++ AVLTree.cpp -o avl
6. In the terminal, run this: ./avl 

I did not deviate from the instructions as far as I am aware.
